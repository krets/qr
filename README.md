# qr

Just a simple QR code generator I threw together for my own needs. I wanted a way to easily share my contact info as a vCard directly from my phone, so I built this.

You can use the live version here:
[https://qr.krets.com/](https://qr.krets.com/)

It's pretty straightforward. It runs entirely in your browser (no server-side data processing), supports Wi-Fi and vCard generation, and even saves your design settings inside the downloaded PNG metadata so you can edit them later.

If you stumble across this and find a bug, feel free to open an issue:
[https://github.com/krets/qr/issues](https://github.com/krets/qr/issues)
